BNL executable preview

This directory contains the compiled Backend as Natural Language runtime and its public browser bridge. The runtime executes user-owned data locally; it does not expose a native host or external delivery adapters.

The compiled bnl-playground.wasm artifact is excluded from the portfolio repository's MIT license. BNL source licensing has not been selected. This public preview does not grant an open-source license to the private BNL project.

See build-manifest.json for provenance and THIRD-PARTY-NOTICES.txt for dependency licenses. The user-data playground has no preloaded business records.
